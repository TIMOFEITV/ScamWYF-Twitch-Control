# ScamWYF-Twitch-Control
This mod allows your Twitch chat to play as the victims. All they have to do is type in !join, and they will be able to join the caller pool and be a victim you can scam. 

Set up:
 Get [this launcher](https://github.com/swyf-modding/Launcher/tree/v1.5.3)
 Launch it and and set up the game to get modded
 Grab the DLL file and put it in the plugins in BepInEx in the game files
 Launch the game and open the Configuration (the button at the top right)
 Sign in with your twitch (You sign in with the official twitch website with OAuth, this is required so far for multiple reasons but can get split off If you don't want to, although you will lose features)
 Load up and enjoy

 This also comes bundled with timer configure, so you can edit how much time you have if you wanna spend more time with your viewers
